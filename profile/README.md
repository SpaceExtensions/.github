## О проекте

SpaceExtensions - это набор различных инструментов, модулей или технических решений для Creatio/BPMSoft, которые направлены на улучшение производительности самой системы или производительности работы с ней.

- ⚡ За ходом разработки можно следить в [telegram](https://t.me/spaceextensions)
- 💬 По всем вопросам и предложениям пишите нам [на почту](mailto:kannt.sinto@gmail.com).
